# Bank of Anthos — upload kit

Everything to upload into **Indian Banking System → Modules** before pressing **Generate BRD**. Folders mirror the app: `<upload card>/<module tab>/<file>`. On each module tab, upload a folder's files on the card with the same name.

## How to upload

1. Open the app, pick **Indian Banking System**, go to **Modules**.
2. For each row below: open the **module tab**, find the **card**, click **Upload**, select the file(s).
3. Leave the repository link empty (everything the run needs is in this kit), then press **Generate BRD**.
4. When the panel says it is finished, open **Requirements (BRD)** → **Download BRD (PDF)**.

## Honest notes

- **Screenshots** marked _Real page_ are the bank's own frontend pages (its real templates, styles and scripts from `src/frontend`) rendered with the repository's demo seed data (users testuser / alice / bob / eve, the External Bank contact) and captured in a browser. They were not captured from a live deployment; the three `00-…`/`04-…` images are the official screenshots shipped in the repository.
- **Logs**: the repository contains no runtime logs. `log-statements-catalogue.csv` lists every real logging statement in the code. `sample-runtime-log.SYNTHETIC.log` is an _illustration_: every message text in it is copied from a real logging statement, but the timestamps, order and placeholder values are made up. Leave it out if you only want real evidence.
- **Tickets** are the repository's real public GitHub issues (exported via the GitHub API), sorted into module tabs by keywords.
- **Email Notifications**: Bank of Anthos sends no emails or messages, so there is nothing to upload on that card. The BRD will report this as a gap.
- **Cards** and **Loans** tabs have no evidence because the system has no card or loan features; the BRD will show them as gaps with a backlog to build them.
- The **BRD draft** deliberately contains things the code will contradict (a $500 overdraft, a 15-minute session, savings accounts, two-factor login) so the traceability section has something to catch.
